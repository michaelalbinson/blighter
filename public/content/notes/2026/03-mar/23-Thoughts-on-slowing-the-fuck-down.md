Give yourself time to think about what you're actually building and why. Give yourself an opportunity to say, [...] no, we don't need this. 
Set yourself limits on how much code you let the clanker generate per day, in line with your ability to actually review the code.

Anything that defines the gestalt of your system, that is architecture, API, and so on, write it by hand.
