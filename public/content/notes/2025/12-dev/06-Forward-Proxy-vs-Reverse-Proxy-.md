- Forward proxy:
  - forward proxy sits on the client side (between client and internet) and acts as a gateway to the internet
  - main uses: caching frequently accessed content, filtering/blocking certain sites, and providing client anonymity by masking IP addresses.
- Reverse proxy
  - sits on the server side (between internet and server) and acts as a gateway from the internet 
  - main uses: load balancing across servers, TLS termination to reduce server load, security through hiding server IP addresses, caching static content, and enabling A/B testing.
