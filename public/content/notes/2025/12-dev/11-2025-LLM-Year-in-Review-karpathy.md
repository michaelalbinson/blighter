- Reinforcement Learning from Verifiable Rewards (RLVR)
  - train LLMs against automatically verifiable rewards across a number of environments
  - (DeepSeek R1-style)
- Ghosts vs. Animals / Jagged Intelligence
  - we are getting very different entities in the intelligence space
  - each LLM is "spiky" in specific areas of knowledge
  - general apathy and loss of trust in benchmarks in 2025.
    - labs are making "spiky" LLMs that cover benchmarks well, but not the space outside them
- Cursor / new layer of LLM apps
  - "Cursor for X" pattern of startups where they:
    - do the context engineering
    - orchestrate multiple LLM calls in complex DAGs to balance performance and cost
    - offer an autonomy slider
  - unclear how much of a moat these apps will ultimately have
- Claude Code / AI that lives on your computer
  - something that strings together tool use and reasoning for extended problem solving
  - for now it makes sense to run agents on localhost - at some point it'll all go to the cloud
- Vibe coding
  - regular people benefit a lot more from LLMs compared to professionals, corporations and governments
  - it empowers trained professionals to write software that would otherwise never be written
- Nano banana / LLM GUI
  - humans want to talk to LLMs via image/video/voice etc - who will build the full LLM GUI
  - t's about the joint capability coming from text generation, image generation and world knowledge, all tangled up in the model weights
