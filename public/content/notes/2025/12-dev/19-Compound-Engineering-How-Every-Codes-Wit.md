- traditional engineering:
  - each feature to make the next feature harder to build
  - more edge cases, etc
- compound engineering:
  - each feature to make the next feature easier to build
  - learning loop so that bugs, failed tests and insights are documented and used by future agents
- the loop
  - plan - agent reads issues, research approach, and make a plan
  - work - agent does the work
  - review - engineer reviews the output and lessons learned
  - compound - feed results back into the system
