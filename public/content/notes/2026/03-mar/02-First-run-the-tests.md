- Automated tests are no longer optional when working with coding agents.
- old excuses to write them no longer hold true when it's so cheap to create them with agents
- start sessions with this to show agents that
  - there are tests
  - give a sense of project complexity to the agent via test count
  - put agents in a testing mindset
